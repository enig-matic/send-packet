# JANGOTRA - Network Packet Sender

A Python script using Scapy to create and send Ethernet, IP, and TCP packets for networking and cybersecurity learning.

## Features
- Creates custom network packets using Scapy.
- Allows users to enter a target IP address and network interface.
- Sets a packet limit and duration.
- Displays a completion message.

## Requirements
- Python 3
- operating system

## Usage

```bash
sudo python3 ddos.py

Enter the target IP address, network interface, packet count, and duration when prompted.

## Disclaimer

Use this script only in an authorized lab environment. This is a basic packet-sending learning project, not a complete DDoS testing tool.
